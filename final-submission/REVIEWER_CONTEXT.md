# Reviewer Context

## What this repository is

This repository is the evidence archive for the FlyRank AI General AI Fluency internship. It collects assignment submissions and supporting artifacts in one public location so a reviewer can trace the work without relying on an informal folder dump.

## How to review it

Start with `final-submission/FINAL_INDEX.md`. Assignment artifacts are grouped by explicit assignment identifier where available. Capstone, portfolio, supporting work, and final-review material are separated because those artifacts serve different reviewer purposes.

## Important classification rule

The archive does not manufacture Week 01–Week 08 folders for files that do not identify a week. Classification is based on the evidence itself: assignment code first, then project/deliverable type, then source contents. Uncertain material remains in `inbox/` until verified.

## Portfolio context

The portfolio work uses a deliberately restrained identity: Space Grotesk for headings, Inter for body text, Deep Burgundy `#6B1F2A`, Ink `#171717`, and Warm White `#F7F5F2`. The intended mood is quietly technical and deliberate, with typography, spacing, and restraint carrying the visual identity.

## Demo context

The final documentation/demo video is a separate Drive artifact. The permanent link supplied for the submission package will be recorded in the final index/documentation area. The repository should not claim that the video is stored here unless a local copy is actually committed.

## Verification standard

Before final submission, every required deliverable should be reachable from the final index, with external links included only when they are real and verified. The archive should distinguish between completed evidence, pending administration, and living portfolio work rather than presenting assumptions as facts.
