# FlyRank AI Fluency — Internship Work

A public, organized archive of my FlyRank AI General AI Fluency internship work, including assignment submissions, supporting artifacts, capstone work, portfolio decisions, documentation, and final submission materials.

## Organization

This repository intentionally does **not** force every artifact into Week 01–Week 08 folders. Files with clear assignment identifiers will be grouped by assignment; files whose names identify a project, activity, or deliverable type will be grouped by that evidence instead. Unclear files stay in `inbox/` until their contents establish where they belong.

## Upload workflow

1. Upload the existing PDFs/files into `inbox/` without unnecessary renaming.
2. Once the complete set is uploaded, review the actual filenames **and contents**.
3. Files with a clear `FL-XX` identifier move into the matching `assignments/FL-XX/` folder.
4. Capstone, portfolio, and supporting artifacts move into their dedicated folders when the source material supports that classification.
5. Files that are only identifiable by a week, project, or descriptive title are classified by evidence rather than by inventing a week assignment.
6. Anything still uncertain remains in `inbox/` until it can be identified confidently.
7. `final-submission/FINAL_INDEX.md` is the single reviewer entry point.

## Why this structure

The goal is a clean archive, not a folder maze. Assignment codes are the strongest identifiers when they are present. Descriptive artifacts such as portfolio work, stack decisions, capstone evidence, and retrospective material get their own logical homes. This makes the repository useful both as a working archive and as a final reviewer package.

## Evidence policy

This repository is an evidence archive. File placement and labels are based on the actual submitted material. No assignment, week, result, completion status, or external link should be invented merely to make the structure look complete.

## Final reviewer path

A reviewer should eventually be able to start at `final-submission/FINAL_INDEX.md` and reach every required assignment deliverable, capstone evidence, documentation/demo material, portfolio/design evidence, retrospective, and final review/checkpoint material.
